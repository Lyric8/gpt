# 四曲线鼠标轨迹交付回执

## 改动要点

- `_arc_base()` 已由“单圆弧”替换为四条运动链的随机加权叠加：finger / wrist / elbow / shoulder。
- 每次移动按距离档位独立抽样四个权重后归一化：`d < 60`、`60 <= d < 400`、`d >= 400` 三档；所有权重、频率、幅度区间均集中在文件顶部常量。
- 主运动进度仍严格使用 `smootherstep = 6s^5 - 15s^4 + 10s^3`。四分量使用端点桥接波形，并额外乘端点窗 `16*t^2*(1-t)^2`，所以端点位移与一阶附加速度同时归零，不会在最后一步突然“收线”。
- `_segment()` 保留原 3.5% 原地顿挫与后续 2% 微回撤；原逐点 ±1.9px 白噪声由 finger 高频分量取代，避免与四曲线模型重复叠噪。
- 三层行为未改：`pause` 节奏、`move_to/_imprecise_due` 手不稳、`move/_detour_due` 绕远，以及 click/click_point/type_text/clear_field/scroll 均与基线源码逐方法文本比对为 UNCHANGED。
- `Human.PROFILES` 仍为 `skilled` / `casual`；公开调用接口不变；生产文件未新增 import/第三方依赖。
