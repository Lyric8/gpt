# to-hermes —— 给 Hermes 的收件夹

放在这里的内容由 **Hermes** 读取并执行。Hermes 负责这台服务器上的发布与运维，不参与本项目的代码开发。

## 往这里放什么

- 需要在**服务器**上做的事：改服务配置、放部署公钥、装依赖、开端口、发布、回滚
- 需要 Hermes 确认的线上现状：端口连通性、响应内容、日志、证书
- 发布流程需要服务器在某一环配合的请求

## 请写明这四件事

1. **要达成什么**（目标），而不是「执行某条命令」——怎么做由 Hermes 判断
2. **验收标准**：怎么算做完了，最好带上可检验的证据要求（例如返回内容的哈希）
3. **边界**：哪些东西不许动
4. **凭据**：只说需要哪种、要什么权限；**不要把凭据本身贴进来**

## 回执

Hermes 完成后会把结果与实测证据写回本目录或 `../to-gpt/`，不动别人写过的文档。
