# 实拍图片与许可边界

v3 内置50道菜全部有本地实拍图片引用，无AI生成图，也不在运行时搜索或热链第三方图片。图片来自照片资源分支中的 Wikimedia Commons 原始资源，作者、来源和许可保存在 `data/photos.json`。每道操作卡的“照片来源”展开后显示署名、原图链接、许可名称及链接；图片经过裁切/缩放/WebP转码。代码的 MIT 许可不覆盖第三方照片，照片分别保留其原许可。

这些是**同类菜品实拍参考，不是本配方复刻成品**。卡片和操作卡均明确标注。部分参考仅说明呈现形式：孜然牛肉生菜包的参考图为蔬菜馅生菜包，草莓芝士杯为芝士蛋糕参考，不能据照片改变配方材料。青柠虾复用已确认的香草烤虾照片；因此50道菜对应50个照片条目，但不是50张互不相同的摄影作品。

新增菜与替换图片必须同时更新照片说明、来源、作者、许可和本地WebP，不能删除署名或把搜索结果当作自由使用授权。只接受经核对允许当前使用方式的图片；BY-SA等要求对图片改编继续按原许可提供，不把整个项目统称“图片可随便商用”。详细原始追溯见 `PHOTO_SOURCES.md` 和每条元数据链接。

构建硬门禁检查菜谱/照片 ID 一一覆盖、文件路径限于 assets/photos、文件真实为 WebP、单图不超过2MB、尺寸1—4096、署名字段完整和HTTPS链接。浏览器回归进一步对全部50个卡片图片执行解码。自动化只能证明文件完整与署名存在，照片内容/许可正确性仍需要人工来源核查。
