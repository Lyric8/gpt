# 材料形态：逐道定稿，不再让用户选择鲜干

这些是本程序为目标口感和露营成本选择的正式方案，不是声称另一种材料永远不能做。

## 鲜枝迷迭香
牛肉与小奶酪用鲜嫩枝；油脂里短浸出香，再整枝取走。
这两道要热油浸香且不留硬针叶。不是说干迷迭香不能做肉，而是本卡已选定动作。
对应：迷迭香蒜香牛小排、迷迭香热奶酪与脆面包。

## 干迷迭香／百里香／牛至
土豆用切细干迷迭香；口蘑和浓汤用干百里香；希腊鸡与披萨用干牛至。
切细或在湿润油汁中润开；瓶装好存放，份量与时机在各卡固定。
对应：迷迭香拍扁脆土豆、百里香黄油口蘑、玉米土豆奶香浓汤、柠檬牛至鸡腿、薄饼小披萨。

## 鲜罗勒／鲜薄荷
番茄面包与草莓气泡饮用鲜罗勒；米纸卷、薄荷糖、酸奶羊肉与气泡饮用鲜薄荷。
这些卡吃的是鲜叶形态与临用香气。没有瓶装模式，不把新鲜感当可关闭选项。
对应：罗勒番茄脆面包、草莓罗勒气泡饮、鲜虾薄荷米纸卷、焦边菠萝薄荷糖、孜然羊肉与薄荷酸奶、无酒精青柠薄荷气泡饮。

## 鲜欧芹／鲜莳萝
欧芹酸汁以鲜叶为主体、配少量干牛至；莳萝冷酱固定鲜叶。
菜已按冷叶碎的结构定稿。不是要求全库都带，只有选中相应菜才出现在采购单。
对应：欧芹酸汁牛小排、莳萝酸奶三文鱼。

## 粉料与成品酱
咖喱、孜然、肉桂、甜红椒用瓶装干料；大阪烧酱、咖喱酱、芥末、芝麻酱用成品。
不为“手工”给露营增加十几项制酱工作；经典结构不依赖每样都从零做。
对应：椰香沙嗲鸡与花生酱、迷你大阪烧、蜂蜜芥末鸡腿、芝麻柠檬茄子粗泥与脆面包、肉桂丁香无酒精热果饮。

## 鲜蒜形态也必须固定
牛肉拍裂浸油、红椒虾切片、扇贝与茄子做蒜蓉、酸汁用极细少量生末。
这不是同一把蒜末到处放：结构、辣感、焦化风险与加入时机不同，清单保留形态。
对应：迷迭香蒜香牛小排、西班牙风味红椒蒜虾、蒜蓉粉丝扇贝小锅、欧芹酸汁牛小排。

## 完整50道材料决策

| 菜 | 定稿决策 |
|---|---|
| 罗勒番茄脆面包 | 鲜罗勒定稿：这道吃的是临撕叶子的香气和口感。；蒜用切开的鲜蒜瓣擦面包，不带蒜粉。 |
| 迷迭香蒜香牛小排 | 鲜迷迭香嫩枝定稿：温油浸香后能整枝取出，不留硬针叶。；拍裂鲜蒜而非蒜泥；10g黄油用于整盘收尾。 |
| 欧芹酸汁牛小排 | 鲜平叶欧芹作为主体；牛至固定用干碎叶，在醋油里提前润开。；不用搅拌机打泥，保留细叶碎。 |
| 孜然牛肉生菜包 | 沿用已有孜然香辣复合料，不另买纯孜然替代它的克数。；生菜固定鲜叶整片；与生牛肉彻底分盒。 |
| 柠檬牛至鸡腿 | 牛至固定干碎叶，先在柠檬汁中润10分钟。；柠檬现场擦黄皮、再挤汁；不是柠檬香精盐。 |
| 蜂蜜芥末鸡腿 | 直接用第戎芥末成品酱，蜂蜜与水按清单配。；不再叠加香草；先熟再刷糖酱。 |
| 黑椒牛油风味鸡腿 | 用你已有的味好美黑椒牛油；不是融化黄油。；清单量是分装起点，实际盐度按包装，熟后尝再补。 |
| 照烧葱香鸡腿 | 定稿用生抽、白糖和水，做无料理酒版；不再要求选择味醂。；葱用鲜葱段，不换葱粉。 |
| 孜然羊肉与薄荷酸奶 | 孜然用纯粉；薄荷固定鲜食用叶切细进酸奶。；不把干泡茶薄荷当同等清凉叶碎。 |
| 蒜香柠檬大虾 | 少量鲜欧芹收尾；主香是鲜蒜与柠檬皮。；蒜末末段弱火熟香，果汁和叶碎离火后加。 |
| 西班牙风味红椒蒜虾 | 固定瓶装甜红椒粉与辣椒碎，不需要鲜红椒泥。；蒜固定鲜切片；与粉都避免高温烧黑。 |
| 青柠香菜虾 | 香菜固定鲜叶；鱼露与青柠汁提前配好冷藏。；不把香菜籽粉当香菜叶。 |
| 莳萝酸奶三文鱼 | 本菜固定鲜莳萝：它是冷酱主香，不只是可忽略的装饰。；不使用莳萝籽；酱在家拌好冷藏。 |
| 葱姜清焖鲈鱼 | 鲜姜片、鲜葱丝；不需要另外买西式香草。；使用有盖小锅，咸汁不进裸铝箔盒。 |
| 味噌薄刷三文鱼 | 固定白味噌、糖水刷酱；不再额外撒盐。；烤盘中弱火，含糖味噌不上高温空盘。 |
| 花蛤一锅两吃：鲜蒸→豆腐汤 | 定稿清水姜葱蒸贝，不需料理酒或鲜香草。；白胡椒只留一小撮作为汤的末段香。 |
| 百里香黄油口蘑 | 固定干百里香叶，少量揉碎后在热蘑菇汁/黄油里润开。；不用干粉堆顶，也不倒掉凹口原汁。 |
| 酱烧厚切杏鲍菇小排 | 鲜蒜末末段加入；这道不必再买香草。；杏鲍菇定稿，不能按原口蘑大小整只煎。 |
| 味噌黄油玉米 | 白味噌＋无盐黄油定稿；无需鲜叶、也不额外撒盐。 |
| 青柠芝士焦玉米杯 | 甜红椒用瓶装；青柠用鲜汁。；本版是Esquites风味改编，用易买的帕尔玛，不冒充原版奶酪。 |
| 蒜蓉酱香茄子 | 鲜蒜泥先弱火炒熟，不能用蒜粉替代蒜蓉结构。；鲜葱末最后放。 |
| 芝麻柠檬茄子粗泥与脆面包 | 固定Tahini成品浅色芝麻酱、鲜柠檬汁；干孜然少量。；不混入一把鲜香草，不用料理机。 |
| 迷迭香拍扁脆土豆 | 固定干迷迭香碎，先切得很细、混进油；不是整根干针叶撒上去。；土豆在家蒸熟；现场不等生土豆慢煮。 |
| 柠檬黑椒芦笋 | 不用任何额外香草；鲜柠檬皮就是主香。 |
| 酱油焦壳饭团 | 定稿生抽、少量糖水；海苔留给泡饭，不叠太多味。 |
| 芝士豆子脆饼 | 纯孜然用干粉，瓶装熟豆沥干后压碎。；切达与豆馅定稿，不让用户临时选一串奶酪。 |
| 薄饼小披萨 | 干牛至固定；成品披萨酱和低水分马苏里拉。；不把鲜罗勒当必备，也不用湿番茄片压塌饼底。 |
| 迷迭香热奶酪与脆面包 | 鲜迷迭香嫩枝/叶与蒜薄片定稿；少量不堆满。；拆掉所有原包装，放适配耐热小锅，不烧商家木盒。 |
| 柠檬蜂蜜煎奶酪 | 固定可煎烤Halloumi，不加盐；蜂蜜和柠檬出锅后再加。 |
| 焦边菠萝薄荷糖 | 固定鲜食用薄荷；糖是香气载体，份量小。 |
| 焦边热蜜薯与香草冰淇淋 | 固定香草冰淇淋；需要持续≤-18℃冷冻。；没有冷冻条件就不选本菜，程序提醒而非暗换材料。 |
| 巧克力香蕉夹心饼 | 固定黑巧克力碎，不加香草、蜂蜜或花生。 |
| 肉桂黄油热苹果 | 固定瓶装肉桂粉，弱火末段拌入；不需肉桂棒。 |
| 无酒精青柠薄荷气泡饮 | 固定鲜薄荷与鲜青柠，气泡水充分冷藏。；不列冰块为隐藏选配；本版就是无冰冷藏杯。 |
| 草莓罗勒气泡饮 | 固定鲜罗勒和真实草莓；不加青酱、香精、干罗勒。 |
| 压烤牛肉塔可 | 成品番茄酱、蛋黄酱和第戎芥末已定比例；不叠香草。；酸黄瓜必须保留，它不是可有可无的装饰。 |
| 椰香沙嗲鸡与花生酱 | 咖喱粉与红咖喱酱用成熟成品；不从十种香料起配。；椰奶固定无糖烹饪椰奶，花生酱不是花生糖。 |
| 鲜虾薄荷米纸卷 | 鲜薄荷是卷内叶片，固定鲜叶；不撒干粉。；熟虾与生虾在采购里分开，不能自动合并。 |
| 迷你大阪烧 | 大阪烧酱、蛋黄酱用现成瓶装；木鱼花固定即食薄片。；没有鲜香草采购，葱是明确的菜馅。 |
| 泡菜芝士锅底炒饭 | 泡菜与芝士用成品，泡菜先炒香；不追加一堆香草。；米饭采购按熟饭需求折算生米，复热达到74℃。 |
| 焦壳饭团热汤泡 | 用成品出汁粉，不要求现场熬高汤。；海苔和熟芝麻干料即可，不另采购香草。 |
| 番茄甜椒窝蛋配脆面包 | 孜然和甜红椒固定干粉；罐头番茄保留水分与稳定酸甜。；本菜不另加欧芹装饰，不让一次采购多一盒草。 |
| 蒜蓉粉丝扇贝小锅 | 用鲜蒜蓉形成可吃的蒜层，不能用蒜粉冒充。；干粉丝按干重采购，清单不把泡发重当购买重。 |
| 草莓芝士饼干杯 | 奶酪与浓酸奶固定，不让用户再挑凝固粉/打发奶油。；不用鲜香草，也不撒肉桂掩盖莓果。 |
| 炭边棉花糖巧克力夹饼 | 原味棉花糖与黑巧克力固定；不再加蜂蜜或奶酪。 |
| 柠檬蓝莓迷你松饼 | 泡打粉、柠檬皮、蓝莓固定，完全不用额外香草。；不把泡打粉替成小苏打，不做生面糊试味。 |
| 海苔芝麻现爆玉米 | 固定干海苔与熟芝麻，不需奶酪粉。；必须爆米花专用玉米，普通甜玉米不能替代。 |
| 芝麻酸香冷荞麦面 | 熟芝麻、米醋、香油固定，瓶装即可；不加鲜香草。 |
| 玉米土豆奶香浓汤 | 干百里香固定，适合进入湿润汤底；无鲜香草负担。；不额外放奶油、奶酪或培根，本份保留温暖清甜。 |
| 肉桂丁香无酒精热果饮 | 肉桂与丁香固定干整料，比粉更容易全部取出。；橙汁本版代替橙皮，省一颗只取少量皮的水果；不是精确复制原方。 |
